# Codex Activity Logging

Before beginning any task in `apps/quick-chat-api`, read and maintain
`CODEX_WORK_LOG.md`.

Logging is mandatory:

1. Append the user's prompt verbatim to **Prompt History** before running any
   command. Redact secrets, tokens, passwords, and personal data.
2. After every executed command or tool action, append the exact command, its
   exit status, and a short outcome to the active dated work entry.
3. At task completion, record changed files and verification results.
4. Never delete, rewrite, or omit earlier entries; append only.

This logging requirement is in addition to the repository's existing coding,
testing, and safety guidelines.
